# راهنمای جامع GitHub Spec Kit (فارسی)
### GitHub Spec Kit Comprehensive Guide (Persian)

یک راهنمای تعاملی، کامل و مدرن به زبان فارسی برای استفاده از **GitHub Spec Kit** و متدولوژی توسعه مبتنی بر مشخصات (Specification-Driven Development / SDD).

An interactive, comprehensive, and modern guide in Persian for **GitHub Spec Kit** and Specification-Driven Development (SDD).

## ✨ ویژگی‌ها / Features

- 📖 **آموزش گام‌به‌گام**: از شروع پروژه خام (Greenfield) تا پروژه‌های موجود و بزرگ (Brownfield).
- 🧭 **دستورات و اسلش‌کامندها**: راهنمای عملی بیش از ۲۵ دستور و ابزار کاربردی.
- 🎨 **طراحی مدرن و ریسپانسیو**: تایپوگرافی با فونت وزیرمتن، کامنت‌های بهینه‌شده برای RTL و پشتیبانی از تم تاریک و روشن (Dark / Light).
- ⚡ **تک‌فایلی و سریع**: مستندات مستقل بدون وابستگی‌های پیچیده.

- 📖 **Step-by-step Tutorials**: Covers both Greenfield and Brownfield workflows.
- 🧭 **Commands & Slash Commands**: Practical reference for 25+ essential commands.
- 🎨 **Modern & Responsive Design**: Styled with Vazirmatn font, RTL-friendly code comments, and Dark/Light theme toggle.
- ⚡ **Lightweight & Standalone**: Clean single-file documentation.
